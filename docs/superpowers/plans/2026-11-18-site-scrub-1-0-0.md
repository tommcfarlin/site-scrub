# Site Scrub 1.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Site Scrub 1.0.0: domain-level scrubbing with Keep, an Apple-style settings page, optional removal of cookies, cache, and site storage, and a daily update check.

**Architecture:** Pure logic stays in small ES modules that run in Node tests (`lib.js`, `domains.js`, `match.js`, `settings.js`, `version.js`). Browser calls stay in `background.js`, `site-data.js`, `updates.js`, and `options.js`. A generated file holds the public suffix list. There is no build step.

**Tech Stack:** Vanilla JavaScript ES modules, MV3, JSDoc with `// @ts-check`, `node --test`, Playwright for end-to-end tests. Dev-only dependencies: `typescript`, `@types/chrome`, `@playwright/test`.

**Spec:** `docs/superpowers/specs/2026-11-18-site-scrub-1-0-design.md`

## Global Constraints

- Manifest V3. No build step. No runtime dependencies. The shipped files equal the source files.
- Every JS file starts with `// @ts-check`. `npm test` runs `tsc --noEmit`, then `node --test`.
- Default domains: `facebook.com`, `reddit.com`, `linkedin.com`, `x.com`, `twitter.com`.
- Scrub rule: `domains` holds registrable domains. The extension removes every history item with one of those registrable domains. A `kept` entry blocks it. A `kept` entry matches its own hostname and every hostname under it.
- History stays the default. Cookies, cached files, and site storage are off by default. `browsingData` is an optional permission. The extension requests it at the first use of one of those types.
- The update file is `https://pressware.co/extensions/site-scrub/version.json`, shaped `{"version":"1.0.0"}`. The check runs about once a day. A failed request is silent.
- Stored values are untrusted. Accept only strings and booleans of the expected shape.
- Settings page: 680 px column. Light colors `#F5F5F7`, `#FFFFFF`, `#1D1D1F`, `#6E6E73`, `#0071E3`. Dark colors `#000000`, `#1C1C1E`, `#F5F5F7`, `#98989F`, `#0A84FF`. System font stack with Inter as fallback. Mockup: https://claude.ai/artifact/HWgM7mwhajBv2xAh51kEg8
- Branches: `release/1.0.0` is cut from `master`. Each task below becomes one issue with its own branch from the release branch. Commit titles use the commit-lint format.
- Never add a network call except the version file. No history data leaves the browser.

## Review Focus

1. A subdomain of a shared host such as `a.github.io` and `b.github.io` must count as two different sites. Scrubbing one must not remove the other. The plan uses the full public suffix list, private section included.
2. IP addresses, `localhost`, and single-label hosts have no registrable domain. They are never scrubbed and never listed.
3. Malformed stored data (wrong types, missing keys, a string where an array belongs) loads as defaults and never throws.
4. If the user denies the `browsingData` permission, the switch returns to off and history scrubbing still works.
5. A bad `version.json` (not JSON, no `version`, `"1.x"`, `"v2"`) changes nothing and shows no badge.
