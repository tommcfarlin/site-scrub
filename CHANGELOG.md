# Changelog

## 1.0.0 - 2026-11-18

### Added

- Scrub a domain and every subdomain under it.
- Keep a subdomain to protect it.
- Settings page with search, light and dark themes.
- Optional removal of cookies, cached files, and site storage, after the browser asks for permission.
- In-page scrub dialog and a notification fallback for browser pages.
- Daily update check that reads one version number from pressware.co, shown as a toolbar dot and a banner, which you can turn off in Advanced.
